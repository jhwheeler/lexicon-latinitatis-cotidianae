# Lexicon Latīnitātis Cotīdiānae

Everyday English–Latin vocabulary, with macrons, examples, usage notes and sources.

Site: https://jhwheeler.github.io/lexicon-latinitatis-cotidianae/

## Publishing

In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.

The site is the self-contained `index.html`; no build or external dependencies are needed. Changes pushed to the publishing branch update GitHub Pages.

## Updating

The original editable lexicon remains in ChatGPT Library as `Lexicon_Latinitatis_Cotidianae.html`. Copy its revised contents to `index.html`, retaining the website metadata in the head, then commit. Publishing does not automatically synchronize the two copies.
