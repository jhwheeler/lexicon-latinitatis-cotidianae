# Programming vocabulary recovery

Updated 21 October 2026. The live repository had 12 computing groups but omitted vocabulary discussed in other conversations. Ten groups (132–141) were added; the existing 131 groups were retained unchanged. The computing section now has 22 groups and the lexicon has 141.

## Recovered discussion material

- **21 September 2026:** QA and testing: *cūrātiō quālitātis*, *probātiō quālitātis*, tester nouns, six testing types, test cases and conditions, expected/observed results, bug reports, finding/correcting/reproducing a defect. These earlier assistant proposals are not evidence of independent technical usage. The current entries distinguish broad QA from testing, retain *vitium* as an alternative to the lexicon's preferred *mendum*, and use an explicit description for making a bug recur. Historical unmarked spellings are identified as prior proposals.
- **24 September 2026:** project: *cōnsilium* for the plan, *opus* for the work/undertaking. Jack's “Opus incipiamus” is normalized with macrons as *Opus incipiāmus*. No recovered evidence supports claiming that Jack previously chose *inceptum* or *prōiectum*.
- **16 October 2026:** business metrics and email-platform vocabulary: *index numericus*, *numerī*, *mēnsūra*, and recipient-list wording. These remain working extensions, not a community standard.
- **New supporting descriptions:** API-key permissions, reading and writing. These supplement the screenshot context; the entry explicitly says they are not recovered quotations from an earlier vocabulary list.

## Evidence and limits

Successfully inspected Lewis & Short through Alatius for [probātiō](https://alatius.com/ls/index.php?l=probatio), [quālitās](https://alatius.com/ls/index.php?l=qualitas), [cūrātiō](https://alatius.com/ls/index.php?l=curatio), [probātor](https://alatius.com/ls/index.php?l=probator), [cōnsilium](https://alatius.com/ls/index.php?l=consilium), [vitium](https://alatius.com/ls/index.php?l=vitium), [relātiō](https://alatius.com/ls/index.php?l=relatio), [dēstinō](https://alatius.com/ls/index.php?l=destino), [efficiō](https://alatius.com/ls/index.php?l=efficio), [index](https://alatius.com/ls/index.php?l=index), and [mēnsūra](https://alatius.com/ls/index.php?l=mensura). These support component senses and quantities, not standard software phrases. Some other dictionary URLs returned errors and are not represented as independently verified readings. Additional dictionary links in entries are reference pointers.

The earlier comparison in this conversation inspected *Vocabula computatralia*, GNOME's archived Latin translation discussion, and Morgan–Owens. The mailing-list alternative comes from [Vocabula computatralia](https://www.culturaclasica.com/lingualatina/vocabula_computatralia.pdf).

No exhaustive recovery of every historical programming conversation is claimed. The additions cover the specific material retrieved and the missing vocabulary visible in the current conversation. No Library snapshot was used as the editing base.
